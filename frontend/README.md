# Masari — Web Frontend (UI prototype)

Next.js 16 · Tailwind CSS v4 · shadcn/ui (Base UI) · Arabic RTL by default with an English toggle.

> **Program data is real, student data is simulated.** Courses, prerequisites, elective pools and regulations for the
> Mansoura University AI Engineering program come from the [AIE Program Guide](https://aieprogramguide.vercel.app/)
> (an unofficial summary of the bylaws, so verify against the official ones). The student, instructors and seats are demo data.
> No university system is connected.

## Data & rules

| File | What it holds |
|---|---|
| `src/lib/aie-program.ts` | The program: 60 plan entries (incl. 5 elective slots), the L300/L400 elective pools, categories, helpers (`dependentsOf`, `chainDepth`, …) |
| `src/lib/aie-regulations.ts` | Regulations shown in the catalog: load table, grading, assessment, warning, graduation, training |
| `src/lib/rules.ts` | **Deterministic rules engine**: `statusOf` (eligibility), `maxLoad`, `planGraduation` (semester planner) |
| `src/lib/mock-data.ts` | The demo student's record + everything **computed** from it: recommendations, ineligible courses, plan, what-ifs |

The planner assumes each course runs only in its plan term (odd = Fall, even = Spring) and that there's no summer term.
The UI states this assumption.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Screens

| Route | Screen |
|---|---|
| `/` | Student dashboard: GPA, graduation progress, alerts, next-semester proposal, electives |
| `/chat` | Chat with Masari: text and voice input (UI only), verified results, AI explanations, sources |
| `/recommendations` | Ranked courses with live credit-load validation; instructor compatibility with adjustable preferences |
| `/plan` | Multi-semester plan with what-if scenarios (computed by the planner) |
| `/catalog` | Course catalog: all AIE courses with filters, prerequisites, "prerequisite for", elective pools, the student's status per course, plus a Regulations tab |

## Design rule: verified result ≠ AI explanation

Every screen uses the components in `src/components/masari/trust.tsx`:

- `VerifiedBadge` (green): result from the deterministic **rules engine**
- `AiExplanation` / `AiBadge` (violet): wording generated by the **LLM**
- `SourceChip` (blue): citation to a regulation document (**RAG**)
- `ConfidenceMeter`: data-quality signal, e.g. the number of survey responses

Keep this separation when connecting real APIs.

## Brand

Source of truth: `../Masari Project logo brief final/export-8f/` (`masari-colors.css`, logo SVG/PNG). Clean copies of the logos are in `public/brand/`.

| Token | Light | Dark | Use |
|---|---|---|---|
| Primary | `#1E2230` Charcoal | `#F27A2E` Orange (text `#14161F`) | Buttons, ink, logo path |
| Accent | `#F27A2E` Orange | same | The single accent: logo dot, active nav, focus ring. **Fill only**: text uses `--highlight-ink` `#B4501A` |
| Background / Surface | `#F8F8F7` / `#FFFFFF` | `#12141B` / `#1B1E28` | |
| Status | success `#2E9E6A`, warning `#E0A11B`, error `#D14B3F` | | Fills; text uses the `-ink` variants (AA ≥ 5:1) |

Fonts: **Sora** (Latin), **Readex Pro** (Arabic), **JetBrains Mono** (course codes). Arabic text never gets letter-spacing, because it breaks the joins.

Logo rules (`src/components/masari/brand.tsx`):
- `MasariMark` uses the export's exact path (`M24 76 C24 58 50 66 50 50 C50 34 76 42 76 24`). The path is Charcoal on light and White on dark; the orange dot never changes. In Arabic the mark is mirrored and the lockup leads with مساري.
- `AppIcon` (simplified, solid nodes) is for ≤ 32px: the chat avatar and favicons (`src/app/icon.svg`, `apple-icon.png`).

Trust language (provenance by **form**, so there is one accent): solid green = rule-verified, dashed outline = AI explanation, outlined document chip = RAG source.

Layout: top nav on desktop, 5-item bottom tab bar on mobile. The dashboard hero is the "your path" rail (`journey.tsx`), with a compact variant under 640px.

## Structure

```
src/
  app/                    routes (one page.tsx per screen)
  components/masari/      app shell, trust badges, small UI bits
  components/ui/          shadcn/ui primitives
  lib/i18n.tsx            AR/EN dictionary, dir switching, number formatting
  lib/mock-data.ts        demo data, also the draft frontend ↔ backend data contract
```

- Colors are tokens in `src/app/globals.css` (`--verified`, `--ai`, `--source`, `--warning`, plus the shadcn tokens), with light and dark themes.
- For RTL, use logical classes (`ms-`, `pe-`, `start-`, `text-start`) and never `ml-`/`left-`. Wrap course codes in `<Code>` so they don't reorder inside Arabic text.
- `demoCompatibility()` is a placeholder formula. Replace it with the compatibility model's output.
